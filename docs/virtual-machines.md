# 虚拟机模块

本模块提供 libvirt 原生虚拟机的环境检查、创建、发现、启停、开机自启、ISO 弹出和删除。
虚拟机、网络、存储池与磁盘均以宿主机 libvirt 为真源，既有虚拟机无需导入或 KPanel 标签。
用户入口为经典模式「虚拟机」及桌面同名应用。

列表与详情的系统图标读取 libvirt 的 libosinfo 系统声明；快速创建会把所选云镜像系统写入该元数据，
与虚拟机配置一同保留，不依赖名称、磁盘文件名或任务历史。ISO 与既有虚拟机沿用原生系统声明；
没有声明或系统暂未适配时显示通用虚拟机图标。声明不等于探测了客体当前安装的系统，重装后应更新原生声明。

## 创建与管理

- 快速创建：选择 Debian 12 或 Ubuntu 24.04 官方云镜像，填写名称、资源、登录用户名及密码或 SSH 公钥。
  默认创建普通用户；公钥模式禁用密码，密码模式只把 bcrypt 哈希写入任务和初始化配置，明文不持久化、不进入审计。私钥不会发送给 KPanel。镜像通过 HTTPS 从固定官方地址
  下载，校验官方主站清单中的 SHA-512 / SHA-256；不接受自定义下载 URL 或不匹配的镜像。
  Debian 大文件允许一次跳转至固定登记镜像 `saimei.ftp.acc.umu.se` 的同名 HTTPS 文件；校验清单不跳转，其他跳转均拒绝。
- ISO：使用已激活目录存储池中的 ISO 卷。通过既有文件管理器上传后，页面刷新会更新目录存储池的卷索引，再选择镜像并在浏览器 VNC 控制台安装。首个候选面向 Linux；Windows 特定的 UEFI、TPM、
  Secure Boot 与 VirtIO 驱动旅程尚未提供保证。
- 刷新回读真实资源。关机、重启的完成依赖客体系统响应；任务执行完成不能代替系统安装完成或联网成功。
  地址仅来自 libvirt DHCP 租约，没有地址时明确提示通过控制台核对。
- 删除会关闭运行中的虚拟机并移除配置；磁盘默认保留。只有用户显式勾选删除磁盘，才调用 libvirt
  的存储删除动作；失败可能保留部分资源，须通过任务与实际资源核对，不自动重放。

环境自动安装目前只适配具有 apt-get 与 systemd 的 Debian/Ubuntu 主机，使用发行版软件包及其默认
libvirt 网络；不重写物理网卡或创建自定义防火墙模板。其他平台明确提示需要管理员准备依赖。
已安装的 libvirt 可直接使用。缺少活动网络/存储池时提供独立的默认资源准备入口，不重复安装组件。KVM、网络和目录存储池必须实际可用；VPS 可能需要嵌套虚拟化。

## 权限、任务和预算

Panel 保持无特权，Agent 通过固定命令参数调用 `qemu:///system`。浏览器不能提交 Shell、XML、libvirt URI
或控制台目标地址。请求共用登录、Origin、CSRF、严格 JSON、审计与资源版本检查。控制台复用面板
会话，首帧校验 CSRF，20 秒复核会话，凭据不在 URL；VNC 目标由当前域定义取得且限制为回环地址。
cloud-init seed 使用0600，交由 libvirt 按本机安全驱动授予客体进程访问，不向其他本机用户开放。
每端最多 4 个控制台，单帧 1 MiB、会话 2 小时；noVNC 1.7.0 只在打开控制台时加载，不新增监听服务。

写入按既有宿主机写入开关开放。一次只执行一个虚拟机任务，持久化在 Agent 独立私有目录；init manager
启动固定 Agent worker，使任务不依赖页面或 Panel 进程。提交 UUID 去重；过期页面的版本冲突拒绝写入。
任务最多保留约 32 项（达到上限回收最旧的终态记录），单文件 32 KiB；任务目录扫描最多 256 项。
单任务 30 分钟；systemd worker 最长 35 分钟、MemoryMax=1G、TasksMax=128，正常完成后退出。
读取并发 2、请求 15 秒；列表最多 64 台虚拟机、64 个网络/存储池、128 个 ISO。
命令输出限制 2 MiB，错误输出 16 KiB，单个云镜像下载最多 8 GiB；镜像不持久化缓存。
任务失败保留可核对的资源与状态，不在未知执行结果时猜测并删除磁盘。

新增服务为按需原生 Agent 适配，不依赖新的 `kejilion.sh` 协议。现有脚本的 DSM Docker 应用继续沿用
原生命周期，未被本模块替换。`scriptLinkageState=not-required`：无需发布脚本（不适用）；内置脚本
仍为 `614d58cee228007012a2ec602cbdc8dbaeb7950d` / SHA-256
`ec6d52da028ad6c6145fbb9c6796cd1548104b288f9234551c3b3d800b43eec9`。

## 验证与回滚边界

功能候选的实际测试、盲审、Linux 实机和浏览器结果随交付证据给出，不以本说明代替验收。
ARM64、跨发行版、低配长期负载、公开镜像与生产环境均需各自验证。
回滚 KPanel 代码不删除 libvirt 资源、已安装软件包或虚拟磁盘；它们仍可通过原生工具继续管理。
任务正在执行时，应先核对或完成任务，再切换 Agent 版本。
